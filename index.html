DEV LOG · 从 v1.0 到 v4.2
v4.22026.10.24

风圈面积、跨机构对比与导出重构

这一版把“看图”推进到“分析”：当前时次的 34/50kt 风圈用球面多边形实时计算覆盖面积；JTWC / CMA / JMA 的预报路径用红蓝绿虚线同时铺开，并在末端标注机构；BEST 与预报之间的灰色误差连线，把“差了多少”直接画在地图上。导出也从单一 2D 画面扩展到倾斜、抬升与 3D 当前运镜；并加入可调参数的 TC 路径模拟器，支持单条与 3/5 条集合模拟。

PINNED · 联合开发2026.10.24

联合开发声明

本项目由豆包work 2.0 Pro与DeepSeek 4.1 flash大模型联合开发

v4.12026.10.24

路线图发布：把“以后再说”变成可点击的卡片

今天把版本路线图塞进了影棚。四张卡片里只有路径制作器和开发日记是亮的，模拟器与实时播报保持灰度和半透明——它们还没准备好，就不应该装作已经完成。至少从这一版开始，下一步要做什么、为什么还没做，都有了明确的归处。

v3.02026.09.12

动态图标完成纯代码重构

删掉最后一组按等级切图的 PNG，改用 Canvas 路径和逐帧旋转来绘制台风图标。颜色、尺寸、光晕和旋转速度现在全部由风速、气压和当前时次实时驱动。包体没有变大，但图标终于可以跟着数据呼吸，而不是机械地切换图片。

v2.82026.08.20

MP4 逐帧直出引擎上线

用 WebCodecs 加 mp4-muxer，把每一帧 Canvas 直接送进编码器，不再依赖屏幕录制。第一次导出 1080p / 30fps 时，进度条走到 100% 的那一刻，比看到路径画出来还开心。代价是必须处理关键帧、时间戳和取消状态，但成片终于可以脱离浏览器录屏了。

v1.02026.06.02

早期双模式制图的诞生

最早的双模式制图：2D 负责读图，倾斜/立体负责讲故事，两套坐标共用同一条路径数据。那时还没有风圈、没有 3D、没有导出，但“让每条路径成为一部电影”这句话已经写在标题下面了。现在回头看，后面所有功能都是从那一条线长出来的。
